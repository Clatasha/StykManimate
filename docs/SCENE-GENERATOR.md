# Animated scene generator

File → Import → Generate animated scene creates a new editable project through the existing document import path. Existing work stays in its project tab. Save generated work as STYK to preserve the editable camera and effect clips; normal video export uses the existing export pipeline.

Choose 60 seconds, 120 seconds, or a whole custom length from 60 to 600 seconds. Scenes use 24 FPS with one to four characters. Prompt generation recognizes walk, run/chase, punch/jab, kick, block, dodge, jump, fall/trip, get up/recover, wave, celebrate/dance, and idle/wait. Red, Blue, Purple and Green select actors (or Character 1–4). Actions execute in their mentioned order; the pattern repeats with changing reactions over the full duration. Opening and ending sections frame the sequence, and recovery is inserted after falls. This is a bounded local action composer, not a general language model. Unrecognized story details, exact counts, props and dialogue are not interpreted. A prompt with no supported action is rejected instead of silently generating an unrelated scene.

Random generation uses Fight, Chase, Comedy, Everyday or Surprise themes. Each click chooses a new variation seed; enter a saved seed and use a prompt to repeat prompt choreography. The scene's settings, seed and sequence are saved under `_styk.sceneGenerator`. Opening an animation does not require any generator runtime or downloaded models.

The Figures selector offers built-in colored figures and compatible existing project figures: the standard ten-segment humanoid topology, without movieclip, text or image assets. Other rigs remain available for manual editing in the editor. The generator does not attempt to identify arbitrary anatomy.

With effects enabled, strikes get the editor's native Impact punch camera move and Hit flash effect clips. Mention any effect by its editor display name (including Particles, Aura, Energy beam, Smoke and Explosion), or an existing look preset (Power up, Teleport, Impact, Hologram, Ice, Poison, Neon, Golden hour, Retro screen, Energy, Hit flash, Ghost or Retro), to add timed editable clips. Up to eight named effects are added per scene; further effects can be added in the editor. Shake, handheld or zoom requests add native camera clips. Effects are added at selected beats rather than on every frame. Disable the effects checkbox to omit generated effects and impact accents. Automatic camera framing is controlled separately by Camera style. Effects can be adjusted or deleted in the regular inspectors and Advanced timeline.

## Backgrounds and direction

Location offers Rooftop, City street, Forest clearing, Arena and Studio room, plus Plain canvas. Lighting offers Daylight, Sunset and Night. A live preview uses the native export painter. Each seed produces a consistent arrangement and palette for the entire animation; generating another variation changes details while retaining your chosen location and lighting. These are stylized vector compositions, not AI image generation or photorealistic artwork.

Scenery has Distance, Scenery, Stage and Foreground layers with different native parallax responses. Each static layer holds one pose for the whole animation, so a ten-minute scene does not duplicate its scenery thousands of times. Background layers and contact shadows start locked to keep the animation canvas clear; unlock a layer to change its colors, shapes or placement with the existing editor. Actors have individual layers, and generation selects Red when the project opens. The project's color palette includes the scenery colors.

Camera style offers Locked wide, Calm, Cinematic and Intense. Calm keeps wider framing and gentler impact accents; Cinematic moves between establishing, tracking and exchange shots; Intense permits tighter framing and stronger accents. Every frame retains a margin around the actors, including jumps and falls. The base camera is saved as ordinary editable native camera poses, while impact accents remain native camera-motion clips. Locked wide disables automatic framing; turn off impact accents too for a completely static camera. The storyboard labels the planned shot style. Contact shadows can be disabled independently.

Scenery and camera choices remain available for 60–600 second scenes with one to four actors. STYK saves preserve the held sources, layers, palette, native camera keys, and effect clips. Video export uses the same drawing and parallax paths as ordinary projects.

The Fight theme also offers connected **Action choreography** and a **15-second fight demo**; see [Hyperframes integration and limits](HYPERFRAMES.md). Classic movements remain available.

Generation runs in a disposable worker. Native frames transfer in acknowledged 256 KiB chunks. Cancel or close terminates the worker and discards the unfinished result. No inference service, video upload, model download or network API is involved. Scene preparation time displayed in the dialog includes document transfer; opening, playback and video encoding take additional time. This is not a promise of performance on an untested PC.

Verification: `node --test tests/scene-generator.test.mjs`, `node tests/scene-generator.browser.mjs`, `node tests/scene-backgrounds.browser.mjs`, `npm run check`, `npm run changelog:check`. The browser test covers a complete 60-second native project, playback seeking, cancellation, existing effect data, and saving/reopening through the codec.
